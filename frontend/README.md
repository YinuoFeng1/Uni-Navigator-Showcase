# Uni-Navigator Frontend

The current participant interface is `/chat`. `/admin` is for the researcher,
and `/design-lab` is a development-only visual reference. `/study` is retired.

Follow [repository setup](../README.md), then run from this directory:

```bash
pnpm dev --port 3000
```

Checks: `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm build`.
Historical screenshots in `tests/visual/screenshots` are archived fixtures, not
screenshots of the current user interface. Never enter identifying or sensitive
personal information into the prototype.
